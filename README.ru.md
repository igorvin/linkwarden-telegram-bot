# Linkwarden Telegram Bot

Бот сохраняет ссылки из Telegram в Linkwarden. Он работает в личном чате владельца и в одной настроенной группе, включая её темы. «Категория» в интерфейсе Linkwarden называется коллекцией.

## Команды

| Команда | Возможность | Кто может использовать |
|---|---|---|
| `/start` | Получить краткую подсказку | Владелец в личном чате; участники настроенной группы |
| `/bind` | Привязать текущую тему или личный чат к коллекции | Владелец |
| `/unbind` | Удалить привязку только текущей темы или личного чата | Владелец |
| `/settings` | Посмотреть привязку, изменить коллекцию и теги по умолчанию | Владелец |
| `/search текст` | Найти сохранённые ссылки, открыть результат, перейти между страницами | Владелец в личном чате; участники настроенной группы |
| `/scan` | Импортировать старые ссылки из экспорта Telegram; продолжить или отменить импорт | Владелец в теме группы, кроме General |

## Сохранение ссылки

1. Отправьте сообщение с одной или несколькими HTTP/HTTPS-ссылками. Для каждой ссылки бот откроет отдельное меню.
2. Выберите одну коллекцию. В привязанной теме этот шаг пропускается.
3. Отметьте любое число тегов или оставьте выбор пустым. Повторное нажатие снимает отметку.
4. Нажмите **«Готово — сохранить»**. Ссылка сохранится сразу, без отдельного экрана подтверждения.

До последнего шага бот не сохраняет ссылку. Кнопка **«Назад»** возвращает к выбору коллекции, когда тема не привязана. **«Отмена»** закрывает текущий черновик. Меню поддерживают страницы и повтор загрузки после ошибок API.

Бот отвечает в исходной теме. Управлять кнопками может только автор ссылки, в том числе когда другой участник группы является владельцем бота. Сессии выбора истекают через час или при перезапуске бота; после этого отправьте ссылку заново.

## Новая коллекция или тег

Эти кнопки доступны только владельцу бота:

- **«Новая коллекция»** в меню коллекций. Ответьте на отдельный запрос бота названием. Созданная коллекция выберется автоматически, после чего откроется выбор тегов.
- **«Новый тег»** в меню тегов. Ответьте на запрос названием. Бот пришлёт меню под вашим ответом в той же теме: новый тег будет отмечен, остальные выбранные теги сохранятся. Можно добавить ещё один тег, снять отметки или нажать **«Готово — сохранить»**.
- **«Вернуться к выбору»** отменяет ввод названия. **«Отмена»** закрывает черновик.

Старое меню теряет кнопки; его устаревшие запросы также отклоняются сервером. Если новое сообщение отправить не удалось, бот пытается восстановить меню в прежнем сообщении.

Название вводится одной строкой. Максимум для коллекции — 2048 единиц UTF-16, для тега — 50; некоторые эмодзи занимают две единицы. При единственном точном совпадении названия бот использует существующий элемент. Если совпадений несколько, выберите нужный вручную.

Создание доступно также при `/bind`, настройке тегов по умолчанию и подготовке импорта. Оно само по себе не сохраняет ссылку, не запускает импорт и не подтверждает настройки. Отмена черновика не удаляет уже созданную коллекцию или тег из Linkwarden.

## Привязка темы и теги по умолчанию

Вызовите `/bind` именно в нужной теме, выберите коллекцию и подтвердите привязку. Повторный `/bind` меняет её. `/unbind` удаляет связь после подтверждения только для текущей темы или личного чата. Уже сохранённые ссылки и открытые черновики сохраняют свои прежние параметры.

Через `/settings` можно изменить коллекцию, удалить привязку, настроить теги по умолчанию или обновить отображение. Выберите теги и подтвердите **«Сохранить настройки»**. Чтобы убрать теги по умолчанию, снимите все отметки и сохраните.

Новые черновики ссылок и импорта автоматически отмечают теги по умолчанию. Автор может изменить этот выбор; возврат назад не восстанавливает снятые отметки. Настройки каждой темы независимы и сохраняются в SQLite. Удалённые или недоступные элементы обрабатываются без подстановки случайных идентификаторов.

## Поиск

Отправьте `/search рыболовный узел`. Поиск поддерживает название, адрес, описание и теги согласно API установленного Linkwarden. Максимальная длина запроса — 200 символов.

В группе поиск ограничен коллекцией, привязанной к текущей теме. Если привязки нет, сначала используйте `/bind`. В личном чате владельца поиск охватывает доступные API-аккаунту коллекции. Только автор запроса может листать и обновлять его результаты.

Результаты показываются по пять с кнопками открытия в Linkwarden, перехода между страницами, обновления и закрытия. При изменении привязки темы нужно выполнить новый поиск. Поиск ничего не создаёт и не меняет.

## Импорт старых ссылок

Бот не читает историю Telegram напрямую. Для `/scan` нужен экспорт чата из Telegram Desktop в формате JSON.

1. Выполните `/scan` в нужной теме группы, кроме General.
2. Загрузите `result.json` документом в той же теме.
3. Проверьте статистику предварительного просмотра, коллекцию и теги.
4. Нажмите **«Начать импорт»**. Только это подтверждение запускает сохранение.

Ограничения экспорта: 10 МиБ, 100000 сообщений, 10000 уникальных допустимых URL. Бот проверяет группу, определяет тему по полям экспорта и цепочкам ответов, извлекает обычные и скрытые ссылки. Другие темы, собственные сообщения бота и сообщения без подтверждённой принадлежности теме пропускаются. Личный чат и General для импорта не поддерживаются.

Обработка идёт по одной ссылке. Существующие ссылки пропускаются без изменения их коллекции и тегов. При первой ошибке API импорт приостанавливается. Через `/scan` можно продолжить или отменить задание, включая после перезапуска. Автоматического продолжения после перезапуска нет. На тему допускается одно активное задание.

Отмена останавливает последующие запросы; уже отправленный запрос может завершиться. Сохранённые ссылки остаются. Для повторного импорта отменённого набора загрузите экспорт снова — существующие ссылки будут пропущены. Исходный файл обрабатывается в памяти; список URL, параметры и прогресс задания хранятся в SQLite.

## Результат и архивы

После сохранения бот показывает коллекцию, теги и кнопку **«Открыть в Linkwarden»**. Для дубликата отображаются его фактические параметры. Веб-интерфейс Linkwarden по-прежнему требует входа; API-токен в кнопку не включается.

Скриншоты, превью, PDF, HTML и читаемый текст создаёт сам Linkwarden согласно своим настройкам. Отдельной службы скриншотов у бота нет. Бот показывает состояние архивов по API; оно не гарантирует качество изображения или доступность скачивания. Значение «недоступно» может означать как отключённый формат, так и неудачную обработку.

Для новых ссылок бот обновляет то же сообщение до 12 раз с интервалом 10 секунд, пока обработка ожидается. Одновременно допускается до десяти таких наблюдений. Автор может нажать **«Обновить статус»** в активной сессии. Проверки выполняют только GET-запросы и не пересоздают архивы.

## Доступ и защита от повторов

Личный чат разрешён только `ALLOWED_TELEGRAM_USER_ID`. Обычные участники группы `ALLOWED_TELEGRAM_GROUP_ID` могут отправлять ссылки и искать. Запросы из других групп, от ботов, анонимных администраторов и каналов отклоняются. Создание коллекций и тегов, привязки, настройки и импорт разрешены только владельцу.

Каждый callback проверяет автора, чат, тему, сообщение, срок сессии и актуальность кнопки. Данные кнопок используют короткие непрозрачные идентификаторы. Для получения обычных сообщений в группе необходимо соответствующим образом настроить Telegram Privacy Mode.

Ссылки сравниваются по точной строке URL. При обнаружении дубликата в группе бот не раскрывает ID, коллекцию, теги и состояние архивов существующей ссылки. SQLite-журнал предотвращает повторную отправку при повторных нажатиях и перезапусках. Если результат POST неизвестен из-за тайм-аута, ошибки сервера или некорректного ответа, бот сначала ищет созданный объект и блокирует новый POST, пока результат не выяснен. Это применяется также к созданию коллекций и тегов. Редиректы и разные варианты URL не считаются одной строкой. Одновременные записи другими клиентами требуют защиты от дубликатов на стороне Linkwarden.

## Конфигурация и обслуживание

Обязательны `TELEGRAM_TOKEN`, `LINKWARDEN_API_URL`, `LINKWARDEN_API_KEY`, `ALLOWED_TELEGRAM_USER_ID`. `ALLOWED_TELEGRAM_GROUP_ID` включает одну разрешённую группу; значение `0` отключает группы. `LINKWARDEN_PUBLIC_URL` задаёт адрес для кнопок открытия и по умолчанию совпадает с API URL.

`TELEGRAM_TOPIC_COLLECTIONS` задаёт начальные привязки тем JSON-объектом. Сохранённые через команды настройки имеют приоритет; `/unbind` отменяет также такую начальную привязку. `BOT_STATE_PATH` задаёт SQLite; в Compose это `/app/data/submissions.sqlite3` в постоянном томе `bot-state`. Сохраняйте этот том при обновлениях и резервируйте базу перед обслуживанием. Не публикуйте `.env`, токены и экспорт чата в Git.

Коллекции читаются из `response` в `GET /api/v1/collections`; теги — из `data.tags` с курсором `data.nextCursor`. Создание коллекции использует `POST /api/v1/collections` с `{"name":"..."}`, тега — `POST /api/v1/tags` с `{"tags":[{"label":"..."}]}`. Ссылка отправляется с `collection: {id}` и `tags: [{id, name}]`. Идентификаторы читаются из API, а параметры архивирования при создании тегов не переопределяются.

Проверки выполняются отдельно от рабочего контейнера:

```bash
python -m compileall -q bot.py linkwarden.py selection.py submissions.py scan_export.py scan_jobs.py
python -m pytest -q -p no:cacheprovider -o asyncio_default_fixture_loop_scope=function
```

Исправление возврата к меню после создания тега прошло 259 тестов локально и в отдельном Docker-образе на VM. Перед установкой сохраняется образ предыдущей версии и команда отката. Обновление контейнера прерывает открытые интерактивные сессии; настройки и задания импорта сохраняются в томе.
